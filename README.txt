Pibo Collections — เว็บ + Supabase

ไฟล์: index.html (ไฟล์เดียว)
Supabase โปรเจกต์: pibo-collections (https://qncamhrwteeaotlhohav.supabase.co)

ขึ้นเว็บ (Vercel)
1. vercel.com > Add New > Project > อัปโหลดโฟลเดอร์ pibo-website
2. Framework Preset: Other > Deploy
3. ได้ลิงก์ .vercel.app (ตั้งโดเมนร้านได้ที่ Settings > Domains)

ตั้งแอดมินครั้งแรก (ทำครั้งเดียว)
1. เปิดเว็บที่ขึ้นแล้ว แตะโลโก้ P มุมซ้ายบน 5 ครั้งติดกัน
2. ใส่อีเมล manassananwilalai@gmail.com + ตั้งรหัสผ่าน (6 ตัวขึ้นไป) > กด "สมัครครั้งแรก"
3. เปิดอีเมล กดลิงก์ยืนยัน (ถ้าหน้าที่เปิดขึ้นมา error ไม่เป็นไร บัญชียืนยันแล้ว)
4. กลับมาที่เว็บ แตะโลโก้ 5 ครั้ง > ใส่อีเมล/รหัสผ่าน > "เข้าสู่ระบบ"
5. กด 💾 บันทึก ที่แถบดำด้านล่าง 1 ครั้ง = ย้ายสินค้าและรูปทั้งหมดขึ้น Supabase (รอจนขึ้นว่าบันทึกแล้ว)

หลังจากนี้
- แอดมินเพิ่ม/แก้สินค้า อัปรูป ปรับสต๊อก บนเว็บจริงได้เลย ลูกค้าเห็นทันที
- ปุ่ม "ออกจากระบบ" อยู่ที่แถบแอดมิน
- อีเมลอื่นสมัครได้ แต่แก้ร้านไม่ได้ (ล็อกไว้เฉพาะอีเมลแอดมิน)
